# ansible101
Learning Ansible with the wonderful series from [Jeff Geerling](https://www.jeffgeerling.com/blog/2020/ansible-101-jeff-geerling-youtube-streaming-series/)!

My end goal is to configure and harden my Proxmox server solely with Ansible

Check out the [Wiki](https://github.com/barkwoofdog/ansible101/wiki) for each Chapter/Episode. I did not own the book at the time of making this so the tracking between Episodes and Chapters of the book will be slightly off

Please also note that I am using the YouTube series and not the newest version of the book, so some information may be outdated and I am adapting some sections to be more modern. A good example is the episode where Apache Solr is installed (JG installs v8.4 and I am installing v10)

**NOTE:** I swapped to using the Episodes after "Chapter 3" (which is just episode 2) sorry if that is confusing)
